# 查找数据手册 — Chrome 扩展

选中网页上的芯片型号 → 点击选区旁的 **semiee** 或 **LCSC** 浮动按钮 → 打开对应来源的搜索结果页。也可继续使用右键菜单。

支持 **semiee.com（半导小芯）** 和 **LCSC（szlcsc.com）** 两个数据源。两者均停留在搜索页，不自动点击结果、进入产品详情或打开 PDF，由用户自行选择资料。

## 安装与更新

1. Chrome 打开 `chrome://extensions/`。
2. 开启右上角的**开发者模式**。
3. 点击**加载已解压的扩展程序**，选择本项目目录。
4. 更新代码后，点击扩展卡片的刷新图标重新加载，再刷新要使用浮动按钮的网页。

## 使用方法

1. 在任意网页选中芯片型号（如 `STM32F103C8T6`、`EG2124A`）。
2. 点击选区旁的 **semiee** 或 **LCSC** 浮动按钮，或通过右键菜单选择来源。
3. 新标签页显示搜索结果，按需手动选择结果和数据手册。

选中文字只要包含汉字（包括简体、繁体及中英文混合内容），就不显示浮动按钮；例如 `STM32F103C8T6` 正常显示，`STM32芯片` 不显示。

按 Esc、滚动页面或点击其他位置可隐藏按钮。输入框和可编辑区域不显示按钮。浮动按钮用于普通 HTTP/HTTPS 网页；Chrome 内部页面、扩展商店和内置 PDF 阅读器等受限页面不支持。

代码中两个来源均无父菜单。Chrome 会将同一扩展的多个可见菜单项自动折叠到扩展子菜单中，因此单个扩展无法让两个来源同时出现在右键第一层。参见 [Chrome 菜单 API 说明](https://developer.chrome.com/docs/extensions/reference/api/contextMenus)。

## 工作原理

扩展通过 `contextMenus` 创建右键菜单，将所选文本去除首尾空白并进行 URL 编码，再通过 `chrome.tabs.create()` 打开对应搜索地址。搜索页加载后，扩展不再执行页面操作。

`content.js` 监听网页选区变化，在 Shadow DOM 中显示两个搜索链接，点击后在新标签页打开搜索结果，不自动点击结果或跳转 PDF。

## 文件结构

- `manifest.json`：扩展声明、权限、入口及图标。
- `background.js`：菜单创建与搜索页打开逻辑，文件底部提供函数使用例程。
- `content.js`：选中文字后的浮动来源按钮及显示、隐藏逻辑。
- `icons/`：PNG 图标（16/32/48/128）。
- `CHANGELOG.md`：版本更新及历史开发记录。

## 权限说明

使用 `contextMenus` 权限创建右键菜单，并通过声明式内容脚本在普通 HTTP/HTTPS 网页中读取选中文字、显示浮动按钮。只有用户点击来源时，才将所选关键词作为搜索参数发送给对应网站。
